# Evaluate mask-derived weight prediction under a controlled protocol

The Etapa de Predição de Peso will evaluate how well information derived from binary masks predicts live weight, compare geometric and convolutional approaches under a controlled protocol, and identify limitations imposed by the sample and acquisition process. It will seek the lowest credible MAE among predefined candidates rather than continue an open-ended search for the lowest observed OOF value on the same 132 animals.

Feature interpretation for Random Forest and Rede Densa por Feições will combine four complementary results: single-feature performance, retraining after individual removal, permutation on reserved evaluation animals, and Testes de Retirada de Features for redundant groups. Removal measures whether a model can adapt without a feature, while permutation measures how much the fitted model relies on that feature's association with each Máscara Válida. Redundancy motivates controlled removal tests but does not remove a feature automatically.

The Universo de Features Candidatas contains exactly 26 columns: `area`, `perimeter`, `solidity`, `circularity`, `equivalent_diameter`, `bbox_width`, `bbox_height`, `bbox_area`, `aspect_ratio`, `extent`, `convex_area`, `convexity`, `major_axis_length`, `minor_axis_length`, `roundness`, `feret_diameter`, `hu_moment_1`, `hu_moment_2`, `area_power_1_5`, `area_major_axis_product`, `center_vertical_occupancy`, `end_vertical_occupancy_min`, `end_vertical_occupancy_max`, `center_to_end_occupancy_ratio`, `centroid_x_offset`, and `centroid_y_ratio`. Their geometric meanings and scale rules follow `CONTEXT.md`; this inventory does not presume that all 26 survive selection.

The Conjunto Compartilhado de Features follows a conservative removal rule: a feature or redundant group may be removed only when its absence does not worsen any representative Configuração de Modelo beyond the 1 kg practical-equivalence margin and consistently improves at least three of the four representative configurations in either Random Forest or Rede Densa por Feições. The other model class may remain neutral. A single configuration can therefore veto removal, but only when its mean degradation exceeds 1 kg and the degradation is consistent in at least four of the five Divisões Estratificadas. Each division contributes one paired effect summarized from its complete five-fold OOF evaluation; individual folds are not the units counted by the consistency rule. Effects are not averaged across configurations or model classes, so an apparent gain elsewhere cannot hide stable harm and an isolated fluctuation cannot exercise a veto.

The four coarse configurations for each feature-based model class must span distinct capacities and regularization levels and be fixed before feature-removal results are observed. Their exact hyperparameters belong to the unified three-approach evaluation protocol rather than to the feature-contract decision.

The resulting Conjunto Compartilhado de Features is frozen before the best Random Forest and Rede Densa por Feições coarse configurations are selected and undergo Ajuste Fino de Configuração. This later refinement seeks lower MAE and greater stability for each winning model configuration. It cannot reopen feature selection, because doing so would create another selection cycle over the same 132 Máscaras Válidas.

An AI agent will draft a versioned Relatório de Seleção do Conjunto Compartilhado de Features from the recorded protocol and results. The agent may organize evidence and recommend interpretations, but the report and final feature set become authoritative only after explicit human confirmation in a grilling session. The report must summarize every removal test, including neutral, unstable, and rejected results, while linking to separate machine-readable artifacts for configuration- and fold-level detail. Three compact generated figures provide visual evidence: a feature-redundancy heatmap, a removal-effect heatmap across the four Random Forest and four dense-network configurations with consistency indicated, and a dot-and-interval plot of permutation effects for both model classes. This preserves Seleção Manual de Features and creates an auditable but concise intermediate source for the future PIBIC report.

The report structure is fixed: identification and provenance; objective and executive result; selection protocol; evidence sections for redundancy, single-feature performance, permutation, and retrained removal; one complete summary table covering every tested feature or group; the retained and removed features plus the frozen input contract; interpretation and limitations; the human-review record; and links to detailed artifacts and references. Its limitations section must identify the final score as MAE OOF Pós-Seleção and explain that independent confirmation requires new animals. The report is generated only after real results exist, rather than maintained as an empty template.

Selection of the coarse Configuração de Maior Potencial for each model class is documented later in its own report. Keeping the reports separate prevents configuration ranking from influencing the already frozen feature contract.

Feature evidence will be evaluated over five five-fold Divisões Estratificadas. Within each division, the complete feature set and every Teste de Retirada de Features use identical fold assignments, making their MAE differences paired by reserved animals; assignments change between divisions to expose split sensitivity without the cost of the previous thirty-seed analysis.

An absolute MAE difference of at most 1 kg is the practical-equivalence margin for Testes de Retirada de Features. Smaller changes are treated as neutral rather than promoted to an improvement or degradation solely because their numerical sign differs.

A Teste de Retirada de Features is consistent for a configuration only when at least four of the five divisions agree and its mean effect falls in the same practical-effect class. A decrease greater than 1 kg is an improvement, an absolute difference up to 1 kg is neutral, and an increase greater than 1 kg is degradation. Any other pattern is unstable and does not count as improvement. The conservative removal rule permits omission only when no representative configuration is consistently degraded and at least three of the four configurations in one model class consistently improve.

In addition to individual removals, six predeclared group tests cover structurally derived descriptors: area transformations (`equivalent_diameter`, `area_power_1_5`), Bounding Rectangle relations (`bbox_area`, `aspect_ratio`, `extent`), Elipse Equivalente relations (`roundness`, both Hu moments, `area_major_axis_product`), the regional-occupancy relation (`center_to_end_occupancy_ratio`), the convex-hull relation (`solidity`), and the area-contour relation (`circularity`). Each group test retains the underlying measurements so it asks whether supplying the derived relation helps either model.

Permutation evidence uses ten deterministic shuffles per feature in each fold. Across five five-fold divisions this yields 250 held-out permutation effects per feature and model, which is sufficient to summarize reliance without making permutation—not retrained removal—the selection criterion.
